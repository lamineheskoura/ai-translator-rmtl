# Manga AI Editor — محرر ترجمة المانهوا إلى العربية

أداة إنتاجية: تحميل الفصول من المصدر ← ترجمة آلية (API) ← مراجعة بصرية ←
تصدير WebP (صفحات أو شريط Webtoon مدمج/مقطع) — بإحداثيات وأحجام وألوان
ملتقطة من الموقع الأصلي بدقة البكسل.

> **ملاحظة الحقوق:** المحتوى المُترجم ملك ناشريه. هذه الأداة لسير عمل
> فرق الترجمة الخاصة بك فقط.

## التشغيل السريع (Windows)

```bat
install.bat        :: أول مرة فقط: venv + المكتبات + متصفح السكرابر + ملف .env
:: ضع مفاتيح الترجمة في .env (انسخها من .env.example)
start_server.bat   :: يفتح http://127.0.0.1:8000 تلقائياً
```

> **عامل جديد ولا تعرف البرمجة؟** اقرأ `README-WORKERS.txt` — دليل
> عربي خطوة بخطوة بالصور الوصفية: التنصيب، مفتاح الترجمة من زر API،
> أول فصل، الترجمة، المراجعة، التصدير، وحل المشاكل الشائعة.

## سير العمل

1. زر **تحميل**: الصق رابط الفصل (أو عدة روابط / رابط بداية + عدد) — يعمل في الخلفية.
2. زر **ترجمة AI** أو **🔁 إعادة الترجمة** (للنواقص فقط، بمحاولات متكررة).
3. راجع في المحرر (أوضاع: تحرير / مراجعة / مشاهدة فقط) — الأحجام تُضبط تلقائياً.
4. زر **تصدير**: WebP بجودة قابلة للضبط، دمج Webtoon حتى ارتفاع أقصى، ثم ZIP للنشر.
5. بديل بلا API: **تصدير نص** (MANGA-TEXT v1) ← الصقه في أي AI chat ← **استيراد نص** (الحقن حسب معرّف الفقاعة، الإحداثيات لا تُمس).
6. ⚙ **إعدادات**: مجلد المانهوا الرئيسي (كل مانهوا بمجلد باسمها وفصولها تتراكم فيه).

## البنية

```
main.py                  # نقطة الدخول (سيرفر / سكرابر / EXE مستقبلاً)
editor/server.py         # FastAPI: فصول، طابور دفعات، ترجمة، تصدير، إعدادات
editor/exporter.py       # تركيب Pillow (عربي RTL + حدود + ملاءمة مخلصة للموقع)
editor/static/           # المحرر (DOM overlays + Inspector + مراجعة)
scraper/spider.py        # Scrapling Stealth (صور + أوفرلايز + ألوان/خطوط الموقع)
scraper/coordinator.py   # معايرة المقياس/الهيدر + تعيين الإحداثيات لكل صفحة
translator/providers/    # Gemini / Groq / NVIDIA / OpenRouter / مخصص (المفاتيح من .env فقط)
output/<slug>/chapter_N/ # البيانات (لا تُرفع لـgit): pages/ + chapter_data.json + exported/
```

## الإعداد (.env)

```ini
GOOGLE_API_KEY=          # أو GROQ / NVIDIA / OPENROUTER / CUSTOM_*
MANGA_OUTPUT_DIR=        # فارغ = ./output بجانب البرنامج
MANGA_PORT=8000
LOCAL_ADMIN_TOKEN=       # لحماية /api/shutdown
```

لا تُرسل `.env` أو `providers_config.json` أو `output/` لأحد — كلها في `.gitignore`.
حزمة العمال تُبنى بـ `package.bat` (تستثني الأسرار والبيانات تلقائياً).

## المتطلبات

Python 3.10+ · `pip install -r requirements.txt` · أول سكراب يحتاج إنترنت
(تحميل متصفح Stealth + صور الفصل).
